# Claude Profile Manager

**Переключение между несколькими учётными записями Claude в Windows с информацией о плане,
подписке и расходе лимитов по каждой — без ручного входа и выхода.**

Переключатель аккаунтов и панель расхода для **Claude Desktop** и **Claude Code**.
Хранит отдельный слот на каждую учётную запись, перекладывает файлы сессии и читает данные
о расходе, которые Claude и так держит на диске, — включая тот аккаунт, в который вы сейчас
*не* вошли.

## Зачем

Claude Desktop держит вход только в один аккаунт. Если у вас личная подписка Pro и рабочий
Max, переключение означает выход, вход заново и потерю сессии каждый раз. Приложение хранит
файлы учётной записи в слотах и перекладывает их, поэтому сессия, куки и учётка Claude Code
возвращаются ровно в том виде, в каком вы их оставили.

## Возможности

- **Переключение профилей** — любое количество аккаунтов. Одна кнопка закрывает Claude,
  перекладывает файлы и запускает его снова. Все перемещения журналируются и откатываются
  при сбое на середине.
- **Данные аккаунта** — план (Pro / Max 5x / Max 20x), тариф лимитов, способ оплаты, дата
  подписки, организация, extra usage. Показываются и для неактивных профилей.
- **Лимиты** — текущий расход 5-часового и недельного окна, оценка времени сброса, график
  истории с разрывами там, где Claude был закрыт, пики по дням и сравнение всех профилей.
- **Расход Claude Code** — токены из локальных транскриптов по дням, моделям и проектам.
- **Значок в трее** — расход в подсказке, быстрое переключение, запуск и закрытие Claude,
  переключатели уведомлений и автозапуска.
- **Уведомления** — при пересечении порога лимита и при его сбросе.
- **Автозапуск** — по желанию при входе в Windows, сразу свёрнутым в трей.
- **Тёмная, светлая и системная тема.**
- **8 языков** — English, Deutsch, Español, Français, 日本語, Português, Русский, 简体中文.
  По умолчанию берётся язык системы.
- **Точные цифры по желанию** — выключено по умолчанию, спрашивается один раз. См. ниже.
- **Без рантайм-зависимостей, без телеметрии.**

## Оценки и как сделать их точными

Проценты расхода, прочитанные с диска, точны — это те же числа, что показывает Claude.
**Времена сброса — нет.** В файле лежат значения, округлённые до целых процентов, с шагом
около 15 минут, поэтому момент начала окна из него не восстановить. Приложение пишет
«сброс не позже 18:42» вместо выдуманного точного времени и честно говорит, когда
недельный сброс ни разу не наблюдался.

Два способа получить точное время:

1. **Калибровка** (без сети). Окно расхода самого Claude называет недельный сброс,
   например «Resets Wed 7:00 AM». Введите это один раз — понимается и строка целиком —
   и дальше значение будет точным. Якорь также определяется сам при первом наблюдённом
   сбросе.
2. **Точные лимиты через API** (по согласию, ходит в сеть). Читает OAuth-токен, который
   Claude Code сохранил локально, и запрашивает точные цифры у
   `api.anthropic.com/api/oauth/usage`. Выключено по умолчанию, спрашивается один раз при
   первом запуске, по умолчанию только для активного профиля. Работает лишь для профилей,
   вошедших в Claude Code; иначе приложение предложит ввести токен вручную. Подробности —
   в [SECURITY.md](SECURITY.md).

## Установка

Скачайте из раздела [Releases](../../releases):

- **`Claude Profile Manager-Setup-<версия>.exe`** — установщик с ярлыками в меню «Пуск»
  и на рабочем столе.
- **`Claude Profile Manager-<версия>-portable.exe`** — один файл, без установки.

Windows 10 или 11, x64. Сборки не подписаны, поэтому SmartScreen предупредит при первом
запуске — «Подробнее» → «Выполнить в любом случае». Не хотите этого? Соберите сами, это
занимает минуту.

## Как работает переключение

Профиль — это набор файлов, определяющих вошедшую учётную запись. Они перекладываются между
рабочими путями и слотом хранилища `~/.claude-profiles/<слот>`:

| Откуда | Что | К чему относится |
|---|---|---|
| `%APPDATA%\Claude` | `Network`, `Local Storage`, `Session Storage`, `IndexedDB`, `Local State`, `config.json` | Claude Desktop |
| `%USERPROFILE%` | `.claude.json` | Claude Code |
| `%USERPROFILE%\.claude` | `.credentials.json` | Claude Code |

Имя активного слота лежит в `~/.claude-profiles/current.txt`.

**Во время переключения Claude должен быть закрыт** — подмена файлов у живого процесса ломает
профиль. Приложение это проверяет, предлагает закрыть Claude (сначала мягко, затем
принудительно) и журналирует каждое перемещение, чтобы сбой откатывался, а не оставлял всё
в половинчатом состоянии.

`plan-usage-history.json` намеренно **не** переключается. Каждый замер в нём помечен
идентификатором организации, поэтому один общий файл хранит историю лимитов всех аккаунтов —
именно это и позволяет их сравнивать.

### Не только настольное приложение

Claude Code — командная строка и расширения для редакторов — входит через `~/.claude`,
и эта папка по умолчанию входит в переключаемый набор. В разделе **Настройки → Claude**
можно сузить область до «только Desktop» или «только Claude Code», если нужно, чтобы они
жили независимо.

## Откуда берутся данные

Всё читается из файлов, которые ведёт сам Claude. Сеть не используется.

| Источник | Для чего |
|---|---|
| `~/.claude.json` → `oauthAccount` | план, тариф, оплата, даты подписки, организация |
| `~/.claude-profiles/<слот>/home_.claude.json` | то же самое для неактивных профилей |
| `%APPDATA%\Claude\plan-usage-history.json` | проценты 5-часового и недельного окна во времени |
| `~/.claude/projects/**/*.jsonl` | токены Claude Code по дням, моделям и проектам |

Время сброса вычисляется по моменту последнего обнуления счётчика, поэтому это оценка,
а не официальная дата. Итоги Claude Code общие для всех аккаунтов: папка
`~/.claude/projects` не входит в переключаемый набор.

## Добавление аккаунта

1. **Добавить профиль** в боковой панели, задать имя слота.
2. Переключиться на него — Claude запустится без входа.
3. Войти в нужную учётную запись.
4. Следующее переключение сохранит эту сессию в слот.

Удаление профиля переносит его в `~/.claude-profiles/_trash/<слот>-<дата>`, а не стирает.
Активный профиль удалить нельзя.

## Структура проекта

```
src/
  main.js              главный процесс Electron: окна, трей, автозапуск, уведомления, IPC
  preload.js           мост contextBridge
  core/
    paths.js           пути и набор переключаемых файлов
    config.js          хранилище настроек в userData
    claudeApp.js       поиск, запуск и закрытие Claude Desktop, обнаружение Claude Code
    profiles.js        чтение профилей, переключение с откатом, управление слотами
    usage.js           разбор plan-usage-history.json, окна лимитов, оценка сброса
    cliusage.js        агрегация токенов Claude Code с кэшем по mtime + size
  i18n/                по файлу на язык, en.js — эталон
  renderer/            главное окно, настройки и окно согласия; графики — инлайновый SVG
tools/make-icon.js     генератор иконок на одном zlib
```

Единственная зависимость — Electron. Графики нарисованы вручную в SVG, иконки генерируются
из сырых пикселей: ни библиотеки графиков, ни инструментов для картинок.

## Совместимость

Пока только Windows. Обе версии Claude Desktop определяются автоматически: сборка из
Microsoft Store (MSIX) запускается через AppUserModelID, сборка из установщика (Squirrel) —
напрямую по exe. Если автоопределение выбрало не ту, переопределите в
**Настройки → Claude**.

Для macOS и Linux понадобятся другие пути и другой способ запускать и закрывать приложение;
ядро, перекладывающее файлы, уже не зависит от платформы. Помощь приветствуется.

Список переключаемых файлов соответствует тому, как Claude Desktop хранит данные сегодня.
Если будущая версия начнёт держать сессию в другом месте, набор придётся обновить — это
самый вероятный способ сломать проект и самая полезная тема для issue.
